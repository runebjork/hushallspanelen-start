# Hushållspanelen – start page

Home-screen start page for [Hushållspanelen](https://runebjork.github.io/hushallspanelen-start/). It shows the app icon and forwards to the app; it holds no data, and access is decided by Google sign-in in the app itself.

Add it to a phone's home screen from <https://runebjork.github.io/hushallspanelen-start/?stay>.

The source lives in the private `hushallspanelen` repo under `launcher/`; icons are generated by `scripts/make_icons.py` there.
